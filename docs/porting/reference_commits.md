## Silero VAD

- **Pin:** `v6.2` (latest model release family; upstream GitHub tag v6.2)
- **Repo:** `https://github.com/snakers4/silero-vad`
- **Sole source (GitHub):** the official v6.2 torchscript checkpoint
  `https://raw.githubusercontent.com/snakers4/silero-vad/v6.2/src/silero_vad/data/silero_vad.jit`
  (~2.3 MB). No HuggingFace mirrors are used. The jit's 16k submodule weights are
  numerically identical to the upstream PyPI `silero-vad` v6.2.1 (2026-02-24)
  checkpoint.
- **speech.cpp asset (format difference):** the engine runtime
  (`src/models/silero_vad/runtime.cpp`) loads safetensors, NOT torchscript — tensor
  names `stft_conv.weight`, `conv1.weight`, ... `lstm_cell.weight_ih/hh`, ...,
  `final_conv.bias` (tinygrad-model key layout, shapes
  `{258,1,256}`/`{128,129,3}`/`{64,128,3}`/`{64,64,3}`/`{128,64,3}`/
  `{512,128}`/`{512,128}`/`{1,128,1}`).
- **Engine asset (DONE Phase 0):** `assets/framework/models/silero_vad/
  silero_vad_16k.safetensors` is **generated from the official v6.2 jit** (see
  `scripts/fetch_silero_vad.py`), remapping jit keys (`_model.encoder.N.reparam_conv.*`,
  `_model.decoder.rnn.*`, `_model.decoder.decoder.2.*`, `_model.stft.forward_basis_buffer`)
  to the runtime keys. **Verified 2026-08-19:** 15/15 tensors generated with max_diff 0;
  sha256 `D7FB67A5B4DE0414A0178270EE81439B9E3067C883C304AA758C247D50FFD79D` (1,239,740 B).
- **WARNING (divergence):** the upstream tinygrad safetensors (snakers4 master
  `src/silero_vad/data/silero_vad_16k.safetensors`, added 2025-12-10 "add tinygrad
  model", commit `fb7d7c7f5d`) is a **divergent export** — its weights do NOT match
  the v6.2 jit (only the deterministic STFT basis is identical; conv/LSTM
  differ). See snakers4/silero-vad issue #768. The old speech.cpp/audio.cpp bundled
  asset (sha256 `C59271C2...`, byte-identical to that upstream file) was therefore
  NOT true v6.2. Do not re-bundle it.
- **Spec:** `model_specs/silero_vad.json` (created Phase 0)
