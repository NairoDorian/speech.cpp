# transcribe.cpp triage ledger

speech.cpp is **equally** a child of `audio.cpp` and `transcribe.cpp`
(AGENTS.md "Dual Parentage"). audio.cpp is the git fork base, so its commits are
absorbed with a recorded merge and git can count what is left. transcribe.cpp has
no merge-base here, so git cannot tell us which of its commits we have absorbed.
This file is that record.

`scripts/sync-deps.sh` reads the line below and reports every non-merge commit in
the sibling checkout (`../transcribe.cpp`, `origin/main`) past it.

Triage watermark: `0a67b65b901deab26e6498bad76d48cf1b6833f1`

## Rules

1. **Audit by content, not by subject.** Find the target code in this tree
   (paths moved: `src/*` -> `src/runtime/*`, `src/arch/<f>` -> `src/runtime/arch/<f>`
   or, for a retired arch, the engine package `src/models/<f>`; `ggml/` ->
   `external/ggml` + `patches/ggml/`), check the symbols it calls exist, and
   `git apply --check` where it applies at all.
2. **A fix to a retired arch is not automatically N/A.** If the defect or the
   feature exists in the engine package that replaced the arch, the disposition is
   PORT-TO-ENGINE, with the target file named.
3. **Every commit gets a row** before the watermark moves past it. Dispositions:
   ADOPT-CLEAN, ADOPT-ADAPT, PORT-TO-ENGINE, ALREADY-PRESENT (cite where),
   N/A (concrete reason), DEFER (scope + where it is tracked).
4. **Advance the watermark only to a commit whose every ancestor is dispositioned.**
   A partially triaged range keeps the old watermark.

### Surprises

1. **The C ABI ITN mapping is broken for engine families, and nothing in this range touches the adapter.** 9eed7f09 changes a retired arch's default, which looks N/A, but auditing the equivalent path found that `transcribe-arch-adapter.cpp:505` stringifies the enum. `TRANSCRIBE_ITN_MODE_OFF` therefore *enables* ITN and `TRANSCRIBE_ITN_MODE_ON` throws `enable_itn must be true/false...` for `sense_asr` and `fun_asr_nano`. The engine defaults themselves are also inconsistent across the ABI: sense_asr=true matches transcribe's new default, while fun_asr_nano=true (`include/engine/models/fun_asr_nano/types.h:44`) does not match transcribe's `itn=False` default, though that is masked today because DEFAULT is forced to "0".
2. **R2T2 is arriving from the other parent.** transcribe's R2T2 port (2d6d2271) says it adopts "the package as repackaged by the sibling audio.cpp runtime". That package is audio.cpp `a7b58a6d` (#604, 2026-09-19), which speech.cpp has not merged yet (last merge: c0b26a50). The bug transcribe fixed in 47d8c5da (one decode per buffered chunk, so lag grows without bound) is present verbatim in audio.cpp's `confucius4_r2t2/session.cpp:507`. speech.cpp will inherit it on the next audio.cpp merge unless it is fixed there, which is also a candidate to report upstream to audio.cpp.
3. **A pre-watermark gap.** `src/runtime/transcribe-batch-util.cpp` is the only runtime file that is not at 2102bca. It is at the pre-8fecde41 state (2026-08-20, an ancestor of 2102bca) and lacks the node profiler (`TRANSCRIBE_PERF_DEBUG=nodes`) and perf-core counting. The 2102bca watermark therefore overstated what was absorbed for that file. It is mostly moot now, because 28a3f985 reverted perf-core counting upstream, but the node profiler and threadpool plumbing are still missing (S1).
4. **A hidden behaviour flip inside the VAD mega-commit.** 6c767184 also turns on the static step-decode graph on **CPU** for whisper, moonshine and cohere (`use_step_graph = primary_is_gpu || !TRANSCRIBE_DISABLE_STATIC_DECODE`). It also defaults `enable_vad=true` for every stream, with a fast path that skips feeding during silence. Either one, adopted as a side effect of taking that commit, would move speech.cpp's whisper .bin gate and streaming semantics. speech.cpp's header states "Streaming runs never use VAD".
5. **Upstream reverted a revert.** edaacaff restored the materialized rel_shift to fix CUDA streaming. The next upstream merge (b174a427) reintroduced the diagonal view and `split_flash_mask`, and be7a8b35 then fixed the actual root cause (the CUDA binbcast stride on the singleton T_q axis). Anyone replaying commits in order would apply edaacaff and then fight it, so skip it.

7. **The ggml ALREADY-PRESENT dispositions rest on uncommitted state.** The 456172ec bump, patches 0008-0011 and the 0007 replacement exist only in speech.cpp's working tree (309 modified paths). Until that is committed, 4923141e and the b796cf79 patch half are not actually present in any commit.
